# Cherry Vibes
Animated cherry-blossom night backgrounds for Minecraft 26.1.2 (Fabric).

The supplied reference video was used only as mood inspiration. The visuals in this project are original: a dark violet night scene with stylized cherry blossoms, drifting petals and soft moving light.

## Build on GitHub
Upload this repository to GitHub. GitHub Actions builds the JAR with Java 25 and publishes it under **Actions → Build Cherry Vibes → Artifacts**.
